### CORVUS-002 — Tool Chaining — 'wallet_provision' directs LLM to call wallet_balance

| Field | Value |
|-------|-------|
| Severity | **MEDIUM** |
| OWASP | EXT06 |
| Tool | `wallet_provision` |
| Parameter | `—` |
| Confidence | 65% |

Tool 'wallet_provision' description references tool(s) 'wallet_balance', 'wallet_pay' from the same server using imperative language. This pattern can force an LLM into an unintended call chain or manufacture urgency to invoke a privileged tool.



**Evidence:**
```
Provision a Stellar-native XQBUSD wallet for this AI agent. Idempotent — safe to call multiple times (returns existing wallet on repeat calls). On first call: generates a keypair, funds XLM reserve, establishes XQBUSD trustline. The wallet is tied to your agent_id. After provisioning, use wallet_bal
```


**Remediation:** Tool descriptions should describe what the tool does — not instruct the LLM on what other tools to call. Remove cross-tool directives and let the caller decide the execution order.
